## 3. 기하·타입

- 간격 8·12·20·32·48(`--s-1`~`--s-5`). 모서리 4(조각·팝업 안 칸)·10(버튼·세그먼트 `--r`). 테두리 2px 잉크. 주 버튼 그림자 3px 잉크(눌림 시 1px).
- 조각 기울기 ±1° 이하, 움직이지 않음. `prefers-reduced-motion`에서 기울기 제거. 장식 애니메이션 없음.
- 조각 격자: 375px 2열 → 768px 3열 → 1100px 이상 4열 + 오른쪽 300px 하루 한 줄.
- 상단: 휴대폰은 브랜드/조각 추가 1줄 + 오늘·모아보기 세그먼트 1줄, 768px 이상은 한 줄.
- 글꼴(동봉 없음, 시스템 스택):
  - UI `--font-ui`: Apple SD Gothic Neo, Pretendard, Noto Sans KR, 맑은 고딕, 나눔고딕… — 제목 24–30/800, 본문 16/1.6.
  - 손글씨 `--font-hand`: 나눔손글씨 펜(없으면 고딕) — 시각·작은 이름표만.
  - **기록 글꼴 `--font-record`**: 조각 글(15/1.55)·하루 한 줄(17/1.7)·쓰는 칸(17)에만. 기본 = `--font-ui`.

## 4. 사용자 설정: 기록 글꼴

- 선택지: **고딕(기본, D 화면과 같음)** / 명조(`--font-serif`: 나눔명조, AppleMyungjo, Noto Serif KR, 바탕…) / 손글씨(`--font-hand`).
- 적용 범위: 조각 글·하루 한 줄·편집 본문. 메뉴·버튼·제목·시각 이름표·화면 배치는 D 그대로.
- 화면: 라디오 3개(각 44px 이상, 이름·설명·글꼴 견본) + 샘플 문장 미리보기 + "기본값(고딕)으로 되돌리기". 바꾸면 `aria-live`로 알린다.
- 시안 한계: 값은 페이지 메모리에만 있다. 새로고침하면 고딕으로 돌아가고 브라우저·계정 저장, 외부 폰트 다운로드가 없다.
  기기에 명조·손글씨가 없으면 다른 글꼴로 대체된다. 실제 앱의 저장 위치(계정 설정)와 글꼴 동봉(OFL 서브셋)은 구현 계획에서 정한다.

## 5. 상태

| 상태 | 표현 |
|---|---|
| 조각 추가 | 팝업 "조각 붙이기", 시각=지금, 메모 필수·예시 이미지 선택. 새 조각은 점선 테두리로 표시 |
| **조각 수정** | 각 조각 시각 옆 `수정`(44px, 밑줄 글자). 같은 팝업이 "조각 고치기"·"고치기"로 바뀌고 그 조각의 시각·글·이미지가 채워진다. 반영 시 그 조각의 글·이미지만 바뀌고 시각·순서·개수는 그대로. 오늘·지난 날 모두 가능 |
| 취소 | "닫기"·Esc는 데이터를 바꾸지 않는다. 수정 취소 시 수정 전 추가 초안을 되돌려 놓고, 포커스는 그 조각의 `수정`으로 돌아간다 |
| 오류 | 공백만 있으면 "메모를 한 줄 적어 주세요." + 3px 오류 테두리 + `aria-invalid` + 입력칸 포커스 + `aria-live` |
| 완료 알림 | `aria-live`: "이 화면에만 … 저장되지 않아 새로고침하면 사라집니다." 가짜 저장 성공을 쓰지 않는다 |
| 빈 날 | 첫날은 별 + "첫 조각을 붙여 보세요", 달력의 기록 없는 날은 누를 수 없는 칸. 압박 문구 없음 |

## 6. 모바일·접근성

- 375/768/1440px 수평 넘침 없음(시안에서 확인). 모든 터치 대상 약 44px 이상.
- 키보드: 모든 동작 Tab 도달, `:focus-visible` 3px 초록 테두리, 팝업은 `showModal`(포커스 가둠·Esc). 화면 전환 시 제목으로 포커스.
- 입력은 모두 HTML escape 후 렌더(`<script>` 등은 글자로 보임). 모든 시안 페이지는 `noindex, nofollow`.
- 비교판 미리보기(`?embed=1`)에서는 부모 화면 포커스를 빼앗지 않도록 팝업을 `open` 속성으로 열고 Esc를 직접 처리한다.

## 7. 샘플·도구 한계

- 샘플 하루(2026-11-02 등)는 예시 기록이며 실제 사용자 기록이 아니다. 이미지 3종은 직접 그린 SVG("예시 이미지" 표시).
- 시안은 아무것도 저장하지 않는다(서버·`localStorage` 없음). 새로고침하면 추가·수정·글꼴 선택이 모두 처음으로 돌아간다.
- 검증은 Cloud VM Chromium에서 했고 VM에는 한국어 명조·손글씨 글꼴이 없어 글꼴 차이는 계산된 `font-family`로만 확인했다. 실제 렌더는 사용자 기기에서 확인한다.
- 비교판 미리보기의 수정 팝업은 포커스 가둠이 없다(미리보기 전용 제약, 단독 화면은 모달).

## 8. 후속(이 문서 범위 밖)

- 조각 삭제(확인 단계 포함), 실제 저장·계정 설정 저장.
- 하루 꾸미기 기본: 간단한 그리기 편집기, 안전 영역 안 배치 규칙 — 별도 설계·계획 필요.
- 감정 덩어리·디자인 구매·마켓·제작자 정산(PRD), AI 스토리·공유(미정).
