세 시안의 공통 가정

  • 제품: 하루의 순간을 기록하고 하루를 정리해 이야기로 쌓는 개인 일기장. 흐름은 순간 기록 → 하루 정리 → 날짜별 다시 보기.
  • 세 안 모두 같은 샘플 하루(2026년 11월 2일)와 같은 화면(오늘·작성·다시 보기·첫날 빈 상태·토큰)을 그렸습니다.
  • 사진+짧은 글, 본인만 보기, 하루 정리는 직접 쓰기는 시안을 위한 가정입니다(PRD 초안 미확정). 감정 기록·AI 스토리·공유는 그리지 않았습니다.
  • 이미지는 직접 그린 예시 그림이고, 글꼴은 기기에 설치된 한국어 글꼴을 써서 기기마다 조금 다르게 보일 수 있습니다.

A 따뜻한 기록장 메인 추천 (가설)

사진과 짧은 글을 날짜별 편집 지면처럼. 따뜻한 종이, 절제된 테라코타, 명조 제목.

A 크게 보기

출발 레퍼런스

Open Design · Warm Editorial (방향만, 값은 새로 정함)

장점

  • 사진이 크게 보여 하루가 한 장의 지면처럼 남음
  • 하단 탭 + "순간 남기기" 하나로 주 동작이 분명
  • 조사 문서 잠정 추천과 같은 방향

주의

  • 사진이 없는 날은 지면이 비어 보일 수 있음
  • 긴 글을 오래 읽기에는 B보다 밀도가 낮음

B 차분한 일기장

날짜 목차와 긴 글 중심의 읽는 화면. 정갈한 종이, 잉크 블루 하나, 명조 본문.

미리보기 안에서 직접 눌러 볼 수 있어요.

B 크게 보기

출발 레퍼런스

Open Design · kami (한국어 렌더는 따로 확인 필요)

장점

  • 하루 정리와 긴 글을 오래 읽기 좋음
  • 날짜 목차·이전/다음 장으로 회상 동선이 짧음
  • 장식이 거의 없어 오래 써도 질리지 않음

주의

  • 사진은 작은 보조라 사진 중심 기록에는 약함
  • 휴대폰에서 빠른 입력보다 "쓰는 페이지" 느낌이 강함

C 조각 모음

사진·메모 조각을 모으는 산뜻한 스크랩북. 달력 칸에 그날의 첫 조각. 손그림은 작게.

미리보기 안에서 직접 눌러 볼 수 있어요.

C 크게 보기

출발 레퍼런스

Open Design · Doodle (원문 하늘색·주황은 글자에 쓰지 않음)

장점

  • "조각을 모은다"는 서비스 이름과 가장 직접 연결
  • 짧은 메모·사진을 가볍게 붙이는 부담 낮은 입력
  • 달력에서 쌓인 날이 한눈에 보임

주의

  • 하루 정리(긴 글)가 보조 위치라 스토리텔링이 약해질 수 있음
  • 오래 쓰면 놀이감이 가볍게 느껴질 수 있음

고르는 방법

A·B·C 중 하나, 또는 "A 바탕에 B의 다시 보기"처럼 조합을 메인에게 알려 주세요. 선택 뒤 그 안만 하이파이로 다듬고 확정 토큰을 정합니다.

선택에 영향을 주는 미확정 질문(PRD 초안):

  • 순간 기록은 짧은 글 중심인가요, 사진 중심인가요? (사진 중심이면 A·C, 글 중심이면 B가 유리)
  • 하루 정리는 직접 쓰나요, AI 초안을 고치나요? (이 시안은 직접 쓰기만 그림)
  • 첫 버전은 본인만 보기로 충분한가요?

예시 이미지 3종은 이 작업에서 직접 그린 SVG입니다(사진 아님). 외부 글꼴·라이브러리·분석 도구를 쓰지 않으며, 입력한 내용은 이 화면 밖으로 보내거나 저장하지 않습니다.
