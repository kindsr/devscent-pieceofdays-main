# 02 Shaping — MVP 한 묶음

- 입력: [01_PRD_ANALYSIS](01_PRD_ANALYSIS.md). 결과: [03_MVP](03_MVP.md).
- 들일 시간(appetite): **[미정]**. 사용자가 일정을 정하지 않았다. 권고는 "기반 골격 + 기록 흐름"을 먼저 한 묶음으로 끝내고, 꾸미기 Lite를 두 번째 묶음으로 나누는 것이다.

## 1. 문제

하루를 한 번에 길게 쓰기는 부담스럽다. 그래서 조각을 가볍게 남기고 저녁에 한 줄로 묶어 보며, 그 화면을 내 취향으로 조금 꾸밀 수 있어야 한다.

## 2. 해법 요소 (D 화면 기준)

| 요소 | 형태 | 비고 |
|---|---|---|
| 오늘 보드 | D의 조각 격자 + "오늘을 한 줄로" | 첫날 빈 상태 포함 |
| 조각 붙이기·고치기 | D 작성 대화상자. 같은 대화상자로 수정, 삭제는 확인 후 | 개별 조각 수정 [확정] |
| 한 줄 정리 | 직접 작성·수정, 하루 1개 | Q2 (A) 가정 |
| 모아보기 | D 달력 → 특정 날 보드 | 빈 날은 그대로 비워 둔다 |
| 설정 | 기록 본문 폰트 선택 | UI 서체는 D 고정 |
| 하루 꾸미기 Lite | 스티커 배치, 그림 칸 펜, 획 지우개, 실행 취소, 저장·적용·되돌리기 | [구조 §3.3](DECORATION_MARKET_ARCHITECTURE.md) |

## 3. 함정과 대응

| 함정 | 대응 |
|---|---|
| 펜 데이터가 커짐 | 획 수·점 수 상한, 저장 전 점 단순화 |
| 폭이 바뀌면 장식이 본문을 덮음 | 슬롯별 고정 비율 칸, 0~1 좌표, 안전 영역 밖이면 숨김 |
| 두 탭·두 기기에서 동시 수정 | 조각과 한 줄에 버전 열을 두고 충돌하면 알린다 |
| 첫 로그인 중복 지급 | 계정당 `grant_key` 유일 제약, 한 트랜잭션 |
| 편집기가 서버 렌더에 섞임 | Konva 모듈은 클라이언트 전용으로 격리 |
| 실제 로그인 결정이 늦어짐 | 로컬·테스트 전용 고정 사용자로 골격을 만들고 배포 이미지에는 넣지 않는다 |
