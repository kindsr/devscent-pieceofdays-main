# 02 Shaping — MVP 한 묶음

- 입력: [01_PRD_ANALYSIS](01_PRD_ANALYSIS.md). 결과: [03_MVP](03_MVP.md).
- 정렬: 2026-11-10 사용자 교정. 사진·메모 몇 줄·설정된 시간으로 회고하며 AI가 하루 이야기를 만드는 것이 핵심이다.
- 들일 시간(appetite): **[미정]**. 사용자가 일정을 정하지 않았다. **[권고]** 구현 의존성은 기반 계정·저장 → 사진·메모·시간 → AI 하루 이야기·날짜별 다시 읽기 순으로 나눈다. 기반 단계만 완료해 MVP로 부르지 않는다. 꾸미기 Lite도 기존 확정 범위로 남긴다.

## 1. 문제

하루를 한 번에 길게 쓰기는 부담스럽다. 사진과 메모 몇 줄을 남기고 시간 맥락으로 회고하면, AI가 하루의 스토리텔링을 만들어 주어야 한다. 직접 쓴 한 줄이나 로그인·메모 저장만으로 이 가치를 대신할 수 없다. 하루를 내 취향으로 꾸미는 기존 요구도 이어 간다.

## 2. 해법 요소 (D 방향을 이어 설계)

| 요소 | 형태 | 비고 |
|---|---|---|
| 오늘 보드 | 사진·짧은 메모 조각과 AI 하루 이야기로 이어지는 자리 | 기존 D 격자를 출발점으로, AI 화면·상태는 아직 설계 필요 |
| 조각 붙이기·고치기 | 실제 사진 업로드·저장과 짧은 메모. 개별 조각 수정 | 입력·보관·실패 정책과 아트보드 필요. 예시 SVG 선택은 실제 업로드가 아님 |
| 시간 | ‘설정된 시간’을 회고에 반영 | 순간별 시각 / 매일 생성 시각 / 둘 다 중 미정. 자동 생성으로 단정하지 않음 |
| AI 하루 이야기 | 사진·메모·시간을 바탕으로 AI가 그날의 이야기를 만듦 | 제공자·전송 조건·비용·생성 동작·사진 분석 범위 미정. 실제 기능 미구현 |
| 이야기 보관·편집 | **[권고]** 날짜별 재조회가 가능하도록 보관 | 수정·재생성·폐기·실패 시 재시도는 설계 제안 단계 |
| 한 줄 기록 | 기존 직접 작성·수정 기능을 보조 기록으로 다룸 | AI 하루 이야기의 대체 완료 기준으로 쓰지 않음 |
| 모아보기 | D 달력 → 특정 날의 AI 이야기와 원래 조각 | 빈 날은 그대로 비워 둠. AI 이야기 읽기 화면은 설계 필요 |
| 설정 | 기록 본문 폰트 선택 | UI 서체는 D 고정 |
| 하루 꾸미기 Lite | 스티커 배치, 그림 칸 펜, 획 지우개, 실행 취소, 저장·적용·되돌리기 | [구조 §3.3](DECORATION_MARKET_ARCHITECTURE.md) |

## 3. 함정과 대응

| 함정 | 대응 |
|---|---|
| 펜 데이터가 커짐 | 획 수·점 수 상한, 저장 전 점 단순화 |
| 폭이 바뀌면 장식이 본문을 덮음 | 슬롯별 고정 비율 칸, 0~1 좌표, 안전 영역 밖이면 숨김 |
| 두 탭·두 기기에서 동시 수정 | 조각과 한 줄에 버전 열을 두고 충돌하면 알린다 |
| 첫 로그인 중복 지급 | 계정당 `grant_key` 유일 제약, 한 트랜잭션 |
| 편집기가 서버 렌더에 섞임 | Konva 모듈은 클라이언트 전용으로 격리 |
| 실제 로그인 연결이 늦어짐 | Google·Kakao 확정. 기반 작업의 로컬·테스트 사용자와 실제 사용자 제공을 구분 |
| 사진 저장을 화면 예시로 대신함 | 실제 업로드·보관·소유자 접근·재접속 조회를 핵심 완료 기준에 포함 |
| 시간 의미를 자동 생성으로 단정함 | 사용자 답 전에는 순간 시각·매일 생성 시각·둘 다를 미정으로 유지 |
| 민감한 사진·메모가 AI로 전송됨 | 제공자·전송 범위·동의·보관·학습 조건을 실제 AI 연결 전에 정함 |
| AI가 없는 사실을 더하거나 생성이 실패함 | **[권고]** 원래 조각과 결과를 대조할 품질 기준, 진행·실패 상태를 설계. 수정·재생성 정책은 미정 |

초기 shaping은 직접 쓰는 한 줄을 하루 정리로 가정하고 AI를 제외했다. 이는 작성 당시의 범위 이력이며, 현재 사용자 교정 이후의 MVP 범위나 AI 제외 승인으로 쓰지 않는다.

## 4. 하지 않는 것

마켓·구매·정산은 확정 후속이다. 전문 드로잉 도구, 공유, 감정 점수·통계, streak·알림 압박, 사진 외 미디어는 제외 제안이다. 사진·짧은 메모·시간 기반 AI 하루 이야기는 제외하지 않는다. 출시 시한이나 자동 생성 스케줄은 확정하지 않는다.
