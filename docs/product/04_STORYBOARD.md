# 04 스토리보드 — 초안 (시안 비교용, 미확정)

- 상태: **초안.** PRD(PR #3 `docs/PRD.md`)가 사용자 응답 전이므로 이 흐름도 가정이다. 시안 3안이 같은 흐름을 그리기 위한 공통 입력이다.
- 근거: README 제품 정의, PRD 초안 §4·§5·§9, [UI/UX 조사](UI_UX_RESEARCH_2026-11-02.md) §3.
- 가정: 1인 개인 일기, 짧은 글 중심 + 사진 선택, 본인만 보기, 하루 정리는 직접 작성(PRD §7 A). 감정·AI·공유는 그리지 않는다.

## 1. 대표 흐름

| 장면 | 사용자 상황 | 화면 | 주 동작 | 끝난 상태 |
|---|---|---|---|---|
| S0 첫날 | 처음 열었다. 기록이 없다 | 빈 상태(압박 없는 안내) | 순간 남기기 | 작성 열림 |
| S1 순간 기록 | 점심에 국수를 먹었다 | 작성(글 필수, 예시 이미지 선택) | 남기기 | 오늘 목록에 시각과 함께 추가 |
| S2 오늘 | 하루 중 조각이 쌓였다 | 오늘(시간순 순간 + 하루 정리 자리) | 순간 남기기 / 하루 정리 쓰기 | — |
| S3 하루 정리 | 밤에 하루를 돌아본다 | 오늘의 하루 정리 편집 | 정리 반영 | 정리 글이 하루 맨 위·끝에 보임 |
| S4 다시 보기 | 며칠 뒤 지난 날을 연다 | 날짜 목록/달력 → 하루 | 날짜 선택 | 그날 정리와 순간을 시간순으로 읽음 |

## 2. 공통 샘플 하루(3안 동일)

- 오늘: 2026년 11월 2일 월요일 — 순간 4개(07:40 창가, 12:15 국수, 16:30 은행나무 길, 21:10 엄마와 통화), 하루 정리 1개.
- 지난 날: 11월 1일(일, 순간 2·정리 있음), 10월 30일(금, 순간 1·정리 없음), 10월 28일(수, 순간 3·정리 있음).
- 기록 없는 날은 표시를 비우거나 흐리게만 한다. 경고·연속 기록 압박을 두지 않는다.
- 샘플 이미지 3종은 직접 그린 SVG이며 "예시 이미지"로 표시한다.

## 4. 미확정 질문(PRD §8 그대로)

1. 처음엔 본인 혼자 쓰는가? 짧은 글 중심인가, 사진 중심인가?
2. 하루 정리는 직접 쓰기(A)인가, AI 초안 고치기(B)인가? B라면 외부 전송 동의 여부.
3. 첫 버전은 본인만 보기로 충분한가?

답에 따라 사진 비중(A·C 유리 / B 불리)과 정리 화면 구조가 바뀐다.
